# Regime-Aware-Portfolio-Allocation
Replication and extension of Vlasiuk &amp; Smirnov (2025) regime-aware universal portfolio using a top-50 US large-cap universe. Compares three regime detectors — Sparse Jump Model, HMM, and RS-GARCH — showing regime awareness cuts volatility by 40% and max drawdown by 70% while maintaining competitive returns.
